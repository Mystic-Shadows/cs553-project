Get Tasks

Returns all tasks stored in the server

    Get Task

    Returns the task associated with the supplied ID

    Make Task (POST)

    Makes a new task

    Replace Task (PUT)

    Replaces a task or makes a new task (only if the id was previously used)

    Edit Task (PATCH)

    Modifies the task that has the supplied ID

    Delete Task

    Removes the task with the supplied ID
